# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-11-18

First release of laravel-quebec-requests: access and portability (Quebec Law 25, s. 27), rectification and deletion (s. 28), de-indexation (s. 28.1) and automated decisions (s. 12.1), due within 30 days (deemed refused after, s. 32), with an identity check, JSON export, anonymization and refusals pointing to the CAI review (s. 34). Part of the Quebec Law 25 suite for Laravel.
